## 프로젝트 개요

---

프로젝트 명: 영상 플랫폼 시스템

개발 목적: 영상 플랫폼을 객체지향적으로 구현해보고자 함.

주요 기능: OOP적으로 가상의 서버를 구현하여 영상 정보 조회, 로그인 등의 동작

## 주요 역할

---

ECB 패턴을 바탕으로 역할과 기능을 나눕니다.

1. 엔티티 (계정, 영상 등의 개별 클래스) - E 
2. 컨트롤 (계정 생성, 삭제 등의 동작, 영상 검색 등의 동작, 서버) - C
3. 사용자 인터페이스 (사용자 입출력, 메뉴 관리) - B

## 목표 구현 기능

---

목적 : 가상의 서버를 구현

1. 영상 정보 조회 및 상호작용
2. 영상 검색 (태그 위주로)
3. 로그인 기능
4. 계정 생성
5. 채널 구독 시스템
6. DataManager - 로컬 파일에 정보 저장 기능 - Entity
7. 로그 기록 시스템
